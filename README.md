# 五甲港口宮 線上求籤

信眾登記 → 選擇問事類別 → 選擇神明 → 搖籤（隨機 5–6 下）→ 開蓋出籤 → 籤詩、白話解釋、命理推算、姓名運程與流年提醒。

純前端靜態網站，可直接用 GitHub Pages 上線；信眾資料透過 Google Apps Script 寫進你自己的 Google 試算表。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁本體（版面、樣式、籤筒插畫） |
| `app.js` | 操作流程、搖籤動畫、結果頁、送出紀錄 |
| `engine.js` | 推算引擎：節氣四季、八字、姓名五格、流年 |
| `config.js` | **設定檔**：貼上 Google 試算表接收網址 |
| `poems.json` | 籤詩庫（160 首，由 `data/src` 編譯而來） |
| `strokes.json` | 康熙筆畫表（20,794 字） |
| `data/src/*.txt` | 籤詩原稿，四類各一檔，方便直接修改 |
| `tools/build_poems.py` | 把原稿編譯成 `poems.json` 並檢查格式 |
| `apps-script/Code.gs` | 貼到 Google 試算表的接收程式 |

## 一、上線到 GitHub Pages

1. 到 repo 的 **Settings → Pages**。
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 約 1 分鐘後網址會出現在同一頁，格式為 `https://<帳號>.github.io/qiuqian/`。

## 二、設定 Google 試算表收集信眾資料

1. 到 [Google 試算表](https://sheets.new) 建立一份空白試算表，命名例如「五甲港口宮 求籤紀錄」。
2. 選單 **擴充功能 → Apps Script**，刪掉預設內容，貼上 `apps-script/Code.gs` 全部內容，按儲存。
3. 右上角 **部署 → 新增部署作業**：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，第一次會要求授權（選你的 Google 帳號 → 進階 → 前往專案 → 允許）。
5. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
6. 打開 repo 的 `config.js`，把網址貼進 `SHEET_ENDPOINT: ""` 的引號中，commit。

之後每次有人求籤，試算表會自動新增一列（第一次會自動建立「求籤紀錄」分頁與標題列）。用瀏覽器打開該網址看到「求籤紀錄接收程式運作中」即代表部署成功。

> 修改 `Code.gs` 後，要用 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」** 重新部署，網址才會沿用。

### 紀錄欄位

時間、姓名、出生日期、性別、電話、類別、神明、時令、籤號、籤等、氣數、八字（年月日）、人格

### 隱私與安全

- 試算表只存在你的 Google 雲端硬碟，預設只有你看得到；不要把試算表設成公開分享。
- 表單有「同意資料紀錄」勾選，未勾選無法求籤。
- 接收網址放在公開網頁裡，任何人都可能送資料進來；程式已限制欄位長度並防止公式注入。若遇到灌資料，可在 Apps Script 重新部署取得新網址。

## 推算方式

**出籤**：籤庫 = 4 類 × 男女 × 四季 × 五籤等（上上、上吉、中吉、中平、中下）＝ 160 首。依「類別／性別／求籤當下季節／推算籤等」取出唯一一首；所選神明只影響畫面與用語。

**籤等由以下加總**（不同類別權重不同）：

- **時令**：以節氣定季節（立春、立夏、立秋、立冬，太陽黃經 315°/45°/135°/225°），各季末約 18 天為土旺用事；五行依「當令者旺、令生者相、生令者休、剋令者囚、令剋者死」。
- **八字**：排年、月、日三柱（立春換年、節氣換月），以日主生月得令與否及其餘干支扶抑判斷身強弱，求喜用五行；看喜用在當下季節的旺衰。
- **用神星**：事業看官星、運勢看財星、感情男看妻星（財）女看夫星（官）、健康看日主，在當季的旺衰。
- **姓名學**：康熙筆畫（部首還原、數字字取其數值），算天、人、地、外、總五格，配 81 數理吉凶與三才生剋；人格五行為喜用者加分。支援常見複姓。
- **性別**：陽年男、陰年女大運順行，反之逆行。
- **當日**：日柱天干是否為喜用、生肖與日支合沖、月亮星座與本命星座相位。
- **神意**：搖籤的隨機數。

**姓名一生運程**：少年運看地格、中年運看人格、晚年運看總格，另說明天格、外格與三才配置。

**流年提醒（未來 12 年）**：生肖與流年地支的值、沖、刑、害太歲；流年天干為劫財提醒防破財；身弱逢七殺提醒壓力；喜用到位且太歲相合標為機運年。

以上為民俗命理推算，僅供參考與心靈指引。

## 修改籤詩

編輯 `data/src/` 裡的 `career.txt`（事業）、`health.txt`（健康）、`love.txt`（感情）、`fortune.txt`（運勢），然後執行：

```bash
python3 tools/build_poems.py
```

每個「## 男 春」區塊下要有 5 首，依序為上上、上吉、中吉、中平、中下；每首是四句七言，格式：

```
四句詩（以，分隔）|白話解釋|宜（以、分隔）|忌（以、分隔）
```

## 本機預覽

```bash
python3 -m http.server 8000
```

再打開 http://localhost:8000 （直接雙擊 index.html 會因瀏覽器限制讀不到 json）。
